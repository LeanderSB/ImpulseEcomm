# Impulse Ecomm — site institucional

Site responsivo em HTML, CSS e JavaScript, sem necessidade de Node.js.

## Abrir no Visual Studio Code
1. Extraia o ZIP e abra a pasta `impulse-ecomm-site` no VS Code.
2. Abra `index.html` no navegador ou use a extensão Live Server.
3. Conteúdo: `index.html`; estilos: `styles.css`; interações e formulário: `script.js`.

## Publicar pelo GitHub Pages
1. Crie um repositório novo no GitHub.
2. Envie os arquivos da pasta para a **raiz** do repositório.
3. Acesse Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Aguarde o link de publicação aparecer na página de configuração.

## Formulário de análise
O cadastro pergunta nome, empresa, WhatsApp, e-mail, se vende em marketplaces, plataformas, nicho, faturamento, ticket médio, plano e desafio. O formulário adapta as perguntas à resposta sobre já vender ou não.

**Importante:** não armazena dados em servidor ou banco de dados. Ao clicar em enviar, abre o WhatsApp com uma mensagem pré-preenchida; o interessado precisa confirmar o envio. Para ter uma lista de leads persistente, será necessário integrar um backend (ex.: Supabase), política de privacidade e proteção anti-spam.

## Conferir antes da publicação
- Plano Completo Online de R$ 2.000/mês é valor sugerido, ainda sujeito à sua aprovação.
- Confirmar permissões de uso de resultados de clientes e escopo dos planos.
- O cabeçalho tem uma marca textual estilizada; a logomarca original está em `assets/logo-original.jpg`.
- Confirmar os termos da análise gratuita e considerar adicionar página de privacidade.
